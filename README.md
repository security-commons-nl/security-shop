# security-shop

Opgegaan in de kennisbank als handleidingen per barriere.

Status: gearchiveerd. De patronen uit deze catalogus zijn herschreven tot handleidingen in de
[kennisbank](https://security-commons-nl.github.io/kennisbank/security/), elk gekoppeld aan een
barriere uit de zelfcheck aanvalspaden. Wat geen barriere raakte, staat als idee in de
[issues van de kennisbank](https://github.com/security-commons-nl/kennisbank/issues?q=label%3Aidee).

Waarom weg: een catalogus met een eigen indeling naast de barrieres uit de zelfcheck betekende twee
namen voor hetzelfde onderwerp, en de lezer moest zelf de vertaalslag maken. De inhoud was juist wat
er ontbrak, dus die is verhuisd in plaats van weggegooid.

## Voor wie

CISO's en ISO's die een maatregel moeten inrichten. Lees de handleidingen op hun nieuwe plek.

## Snel starten

Ga naar [Hoe pak ik het aan](https://security-commons-nl.github.io/aanvalspaden/normen/): per barriere
de handleidingen, met de alternatieven ernaast. Wie liever bij de maatregel begint, kijkt in de
[kennisbank](https://security-commons-nl.github.io/kennisbank/security/).
